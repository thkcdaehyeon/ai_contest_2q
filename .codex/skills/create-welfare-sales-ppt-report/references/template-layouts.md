# Irowoom template layouts

Use the retained `assets/irowoom-template.pptx` as the presentation base. Preserve its slide master, theme, logo, orange/green brand colors, backgrounds, and fonts.

| Source page | Layout | Intended use |
|---|---|---|
| 1 | `제목 슬라이드_01` | Primary cover with orange wave; use for weekly sales reports |
| 2 | `제목 슬라이드_02` | Alternate cover with large translucent logo |
| 3 | `인덱스` | Agenda with numbered sections |
| 4 | `간지` | Section divider |
| 5 | `내용` | Normal content slide with top orange rule and Irowoom logo |
| 6 | `마지막` | Closing or thank-you slide |

The standard five-slide weekly report uses `제목 슬라이드_01` once and `내용` four times. Add agenda, divider, or closing layouts only when the user requests a longer deck.
