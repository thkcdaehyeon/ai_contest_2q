# Required workbook contract

Read the workbook generated by `$update-welfare-sales-workbook`.

- `영업일지`: normalized activities with headers `활동ID`, `활동일`, `담당자`, `사업소명`, `지역`, `접촉방식`, `상담내용`, `관심품목`, `진행단계`, `다음행동`, `예정일`.
- `후속조치`: action rows with `상태` values such as 예정, 지연, 완료.
- `품목_관심도`: product mention counts and percentages.
- `확인필요`: data-quality exceptions to preserve in the deck.

Treat `영업일지` as the source of truth. Read columns by header name and recompute chart series for the requested reporting period.
