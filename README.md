# AI Contest Presentation

## Title

문서를 자동화 자산으로 바꾸는 AI 활용법

## Live Presentation

GitHub Pages 배포 후 아래 형식의 URL로 확인할 수 있습니다.

```txt
https://<username>.github.io/<repo-name>/
```

## Summary

이 발표는 OOXML 기반 문서 파일(.docx, .xlsx, .pptx)을 구조화된 데이터로 이해하고, AI가 생성한 Python 자동화 코드와 안전한 실행기를 통해 반복 문서 작업을 사내 업무 자산으로 전환하는 방법을 제안합니다.

## Recommended Viewing

- Chrome or Edge
- 16:9 display
- Fullscreen mode

## Local Preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`.

## Verification

```bash
node tests/slide-smoke-test.mjs
```

## Backup

If the live page is unavailable, open `index.html` locally or export the deck to PDF from the browser.
