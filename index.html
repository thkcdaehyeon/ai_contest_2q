AI Contest Presentation

문서를 자동화 자산으로 바꾸는 AI 활용법

워드·엑셀·PPT를 파일이 아니라 데이터로 보면, 반복 업무는 AI가 만드는 코드로 자동화할 수 있습니다.

문서는 데이터 AI가 코드 생성 누구나 가능
report.docx구조화된 텍스트
sales.xlsx셀 = 데이터
deck.pptx슬라이드 = XML
script.py자동화 코드
오늘 발표는 AI가 문서를 대신 써준다는 이야기가 아닙니다. 반복되는 문서 작업 자체를 자동화하는 이야기이고, 그게 비개발자도 할 수 있는 일이라는 걸 보여드리는 자리입니다.

오늘의 질문

AI가 반복되는 문서 작업을 자동화해줄 수 있을까?

AI를 '문장 생성기'로만 보면 한계가 있습니다. 하지만 문서를 데이터로 보면, AI는 반복 작업을 자동화하는 코드를 만들어주는 도구가 됩니다. 이 질문의 전환이 오늘 발표 전체의 출발점입니다.

문서의 정체

.docx, .xlsx, .pptx의 x

파일 이름 뒤에 붙은 이 x는 단순한 버전 표시가 아닙니다. 문서 안이 XML이라는 형식의 데이터로 되어 있다는 뜻입니다.

report.docxWord 문서
sales.xlsxExcel 통합 문서
deck.pptxPowerPoint 프레젠테이션
중요한 건 XML 문법을 외우는 게 아닙니다. 우리가 매일 쓰는 문서가 사실은 '구조화된 데이터'라는 사실 하나면 충분합니다.

글을 치면, 프로그램은 뒤에서 XML을 씁니다

Word·Excel·PowerPoint로 작업하는 순간, 내용은 이렇게 XML이라는 형식의 데이터로 저장됩니다.

버튼을 누르면 왼쪽 문서에 글이 입력되고, 오른쪽에 그 글이 XML로 적히는 게 보입니다. 우리가 클릭하고 타이핑할 때마다, 프로그램은 뒤에서 이렇게 데이터를 쓰고 있었습니다. 코드를 외우라는 게 아니라, '문서 = 데이터'를 눈으로 보여주는 장면입니다.

작동 원리

AI가 문서를 수정할 수 있는 이유

마우스로 클릭하는 게 아니라, 문서 속 데이터 구조를 코드로 바꾸는 방식에 가깝습니다.

문서 속 XML 구조

AI의 이해

이 구조를 어떻게 바꿀지 코드로 표현한다

스크립트 실행

from pptx import Presentation
prs = Presentation("deck.pptx")
prs.slides[0].shapes.title.text = "Updated"
prs.save("updated.pptx")

이 코드는 AI가 써줍니다. 우리는 외울 필요 없이, 결과만 확인하면 됩니다.

문서가 자동화에 유리한 이유는 구조가 데이터로 명시되어 있기 때문입니다. AI는 마우스로 문서를 고치는 게 아니라, 그 구조를 코드로 바꿉니다. 코드 화면이 나와도 위축될 필요 없습니다 — 저 코드는 사람이 아니라 AI가 씁니다.

왜 그럴까

같은 AI인데, 왜 PPT는 촌스럽고 HTML은 깔끔할까?

PPT로 만들 때

  • 빈 슬라이드 위에 상자·그림·글자를 하나씩 올리는 방식
  • AI가 "왼쪽으로 조금, 아래로 조금" 위치를 찍어 맞춰야 함
  • 글자가 길어지면 간격과 정렬이 금방 흐트러짐

HTML로 만들 때

  • 제목·본문·카드처럼 먼저 자리를 나눠두는 방식
  • "가운데 정렬", "같은 간격"처럼 정리 규칙을 말로 줄 수 있음
  • 내용이 바뀌어도 브라우저가 규칙대로 다시 정돈함

비유하면, PPT는 종이 위에 스티커를 정확히 붙이는 일이고 HTML은 정리 규칙이 있는 서식을 함께 주는 일입니다.

참고 PPT를 줘도 결과가 촌스러운 건 프롬프트만의 문제가 아닙니다. PPT 자동 생성은 빈 종이 위에 글상자와 그림을 정확한 위치에 하나씩 붙이는 일에 가깝습니다. 그래서 글자가 조금만 길어져도 다시 맞춰야 할 것이 많아집니다. 반대로 HTML/CSS는 제목, 본문, 카드, 간격 같은 정리 규칙을 먼저 말할 수 있고, 브라우저가 그 규칙대로 화면을 다시 정돈해 줍니다. 핵심은 PPT가 나쁘다는 뜻이 아니라, AI에게는 '좌표를 찍어 맞추기'보다 '정리 규칙을 설명하기'가 훨씬 쉽다는 점입니다.

지금 당장

코드 없이, 오늘부터 혼자서도 됩니다

ChatGPT·Claude 같은 AI에 파일을 올리고 말로 시키면, 코드는 AI가 클라우드에서 대신 실행합니다. 내 컴퓨터에 Python을 설치할 필요가 없습니다.

1. 파일 올리기엑셀·워드를 그대로 드래그
2. 말로 시키기"이 파일들 합쳐서 요약 보고서로 만들어줘"
3. 결과 받기완성된 .docx 파일 다운로드

Python 설치 불필요 · 코드는 안 보임 · 클라우드가 대신 실행

비개발자가 오늘 당장 해볼 수 있는 가장 쉬운 경로입니다. 파일을 올리고 말로 시키면 AI가 코드를 내부에서 실행하고 결과 파일만 돌려줍니다. 설치도, 코드도 필요 없습니다. 이게 개인 차원의 출발점입니다.

클라우드 AI의 한계

한두 개는 편한데, 열 개씩 매달이면?

파일 하나를 올리고 말로 시키는 건 정말 편합니다. 그런데 매달 부서별 파일 10개를 똑같이 처리해야 한다면, 이야기가 조금 달라집니다.

클라우드 AI
sales_01.xlsxsales_02.xlsxsales_03.xlsxsales_04.xlsxsales_05.xlsx…sales_10.xlsx
  • 파일 이름·양식·검증 기준을 매번 말로 풀어야 합니다
  • 매번 "무엇을, 어떻게" 다시 설명해야 합니다
  • 담당자가 바뀌면 같은 자동화를 다시 배워야 합니다
  • 다음 달에 또? 같은 업무 맥락을 처음부터 반복
클라우드 AI는 '한 번' 쓰기엔 정말 편합니다. 하지만 같은 작업을 매달 반복하려면 파일 이름, 양식, 검증 기준, 업무 맥락을 매번 다시 설명해야 합니다. 사람이 바뀌어도 같은 설명이 반복됩니다. 버튼을 눌러 이 불편들을 하나씩 보여줍니다. 다음 장에서는 이 반복 설명을 줄이는 방법으로 Skills를 소개합니다.

스크립트 다음 단계

스크립트에 업무 맥락을 입혀 Skills로 만듭니다

스크립트는 반복 실행을 줄입니다. Skills는 그 스크립트를 언제, 어떤 기준으로 쓸지까지 묶어 AI가 이름만 듣고 업무처럼 실행하게 합니다.

자동화 스크립트 업무 설명서 예시·검증 기준
업무 Skills 코드 + 맥락 + 실행 기준
영업팀 재무팀 기획팀

스크립트는 실행을 자동화하고, Skills는 그 자동화를 부를 수 있게 만듭니다.

Skills는 일반 채팅창보다, Codex·Claude Code 같은 AI 에이전트 환경에서 힘을 발휘합니다.

여기서 중요한 구분이 있습니다. 스크립트도 반복 작업을 줄이고, 공유할 수도 있습니다. Skills는 스크립트의 대체재가 아니라, 스크립트에 업무 맥락을 입히는 포장 방식입니다. 어떤 파일을 받아야 하는지, 어떤 스크립트를 실행해야 하는지, 결과를 어떤 기준으로 검증해야 하는지까지 AI가 이해하게 만드는 겁니다. 그래서 팀원은 코드 파일명을 외우거나 사용법을 다시 읽지 않고, '월간 영업 보고서 만들어줘'처럼 업무 이름으로 부를 수 있습니다. 단, Skills는 일반 채팅창보다 Codex나 Claude Code 같은 AI 에이전트 환경에서 힘을 발휘한다는 전제가 있습니다.

한 걸음 더

AI 활용에는 다음 단계가 있습니다

AI를 '초안 도우미'로만 쓰기엔 아깝습니다. 반복되는 문서 작업을 자동화하고, 그 자동화를 팀이 함께 쓰는 단계까지 갈 수 있습니다.

질문하기초안 작성자동화팀과 공유관리·운영

한 단계만 더 올라가도, 같은 일을 두 번 반복하지 않게 됩니다.

사람마다, 부서마다 AI를 쓰는 단계는 제각각입니다. 그래서 '지금 다들 여기 있다'고 단정하지 않습니다. 다만 AI는 초안 작성에서 멈추지 않고 자동화·공유까지 갈 수 있는 도구라는 점, 그리고 한 단계만 올라가도 반복이 사라진다는 점을 전하면 됩니다.

마무리

이제 문서를 '데이터'로 봅시다

문서 = 데이터확장자 속 x는 XML
AI = 자동화말로 시키면 코드 생성
그래서 = 누구나코드 없이 오늘부터

반복되는 문서 작업은, 이제 자동화 후보입니다.

오늘 이후로 문서 작업을 볼 때, '이걸 어떻게 더 잘 만들까'뿐 아니라 '이걸 어떻게 반복하지 않을까'도 같이 떠올리면 좋겠습니다. 그리고 그 출발점은 비개발자인 나도 오늘 당장 시작할 수 있다는 것입니다.
