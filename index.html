Skill

업무 전체를 기억

  • 어떤 요청에 나서야 하는지 알고
  • 필요한 자료를 확인하고
  • 상황에 맞는 도구를 골라 실행하고
  • 회사 양식으로 결과를 만들고
  • 애매한 건 사람에게 묻습니다

AI의 판단과 도구의 행동을, 우리 업무 방식으로 묶어 재사용하는 것 — 그게 Skill입니다.

(2:30–3:30) 프롬프트·매크로와의 차이로 정의. "스크립트를 쉽게 실행하는 포장지"가 아니라는 점을 명확히. Python 같은 도구는 Skill이 부리는 손발일 뿐이라고 한 문장으로 정리.

Skill의 구성

Skill 하나에 담기는 세 가지

업무 지식 + 실행 도구 + 품질 기준
안다

업무 지식

  • 언제 이 업무를 하는가
  • 무엇을 중요하게 보는가
  • 예외 상황엔 어떻게 판단하는가
실행한다

실행 도구

  • 문서 작성과 수정
  • 데이터 분석과 계산
  • 검색·사내 시스템 활용
  • 필요하면 코드 실행까지
확인한다

품질 기준

  • 무엇을 검증해야 하는가
  • 어떤 경우에 멈춰야 하는가
  • 사람이 최종 확인할 것은 무엇인가

한 문장으로: 알고, 실행하고, 확인하는 방법까지 함께 저장합니다.
